# Databricks Ingestion Field Guide

An animated, interactive study guide to data ingestion in Databricks, for the Data Engineer Professional exam (Section 2, Data Ingestion and Loading).

Open `index.html` in a browser, or view it on GitHub Pages.

## What's inside
- What data ingestion is, and the batch, incremental, streaming and CDC patterns
- Lakeflow Connect: managed vs standard connectors
- Unity Catalog storage credentials, external locations and volumes
- Auto Loader: live demo of checkpoints, overwritten files and schema evolution modes
- COPY INTO: idempotency demo, options and CDC behaviour
- Managed database connectors, JDBC partitioned reads, REST APIs with Lakeflow Jobs
- Semi-structured data, partner connectors and a two-click decision guide

Option names and details should be checked against the official Databricks documentation.
