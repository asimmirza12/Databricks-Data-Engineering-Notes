What is data ingestion?

Ingestion is the pipe that moves data from where it is born into the place where you analyse it. In a bank, card swipes live in Oracle, a vendor drops a rewards CSV on S3, and service cases sit in Salesforce. Ingestion brings all of them into Delta tables governed by Unity Catalog, almost always landing in the Bronze layer first.

Where is the data?

Files, a database, a SaaS app, a stream or an API. This picks the tool.

How often does it change?

Once a day means batch. Every second means streaming.

How do I avoid loading twice?

Checkpoint, table metadata, high-water mark or CDC log.

Full batch moves big blocks (everything) each run. Incremental moves only the new slice, then stops. Streaming moves small pieces all the time.

StreamingAlways on, seconds to minutesCard transaction feedAuto Loader continuous, Kafka

In Databricks, "streaming" really means incremental processing. It does not have to run all day.

02

Lakeflow and Lakeflow Connect

Lakeflow has three parts: Connect to ingest, Declarative Pipelines (formerly DLT) to transform, and Jobs to orchestrate. Lakeflow Connect is the umbrella over every ingestion method.

Managed connectors · no code

Databricks runs it

  • Database CDC: SQL Server, Oracle, MySQL, PostgreSQL
  • Query-based: Teradata and others, using a cursor column
  • SaaS: Salesforce, Workday, ServiceNow, Google Analytics, Dynamics 365, NetSuite
Standard connectors · your code

You configure it

  • Files: Auto Loader, COPY INTO, read_files, upload UI
  • Streams: Kafka, Kinesis, Event Hubs, Pub/Sub
Everything else

Fill the gaps

  • Community and custom connectors
  • Partner tools via Partner Connect (Fivetran, Qlik, Informatica)

Auto Loader is a standard connector, not a managed one, even though a Lakeflow pipeline manages its checkpoint for you.

(spark.readStream
   .format("cloudFiles")                         # = use Auto Loader
   .option("cloudFiles.format", "json")
   .option("cloudFiles.schemaLocation", "/Volumes/rewards/bronze/_schemas/fico")
   .option("cloudFiles.inferColumnTypes", "true")
   .load("s3://landing/fico/")
 .writeStream
   .option("checkpointLocation", "/Volumes/rewards/bronze/_chk/fico")
   .trigger(availableNow=True)
   .toTable("rewards.bronze.fico"))
-- SQL: a streaming table uses Auto Loader underneath, checkpoint managed for you
CREATE OR REFRESH STREAMING TABLE rewards.bronze.fico
AS SELECT * FROM STREAM read_files('s3://landing/fico/', format => 'json');

Schema inference

The first run samples up to 1,000 files or 50 GB, whichever comes first, and saves the schema in schemaLocation. Later runs reuse it. Use cloudFiles.schemaHints to pin a type, for example "amount DECIMAL(10,2), customer.age INT".

Schema evolution: what happens when a new column arrives?

Pick a mode and send the file.

Rescued data column

_rescued_data catches type mismatches ("abc" in an INT), extra columns and case mismatches ("Amount" vs "amount"), stored as JSON with the source file path. Alert on WHERE _rescued_data IS NOT NULL.

File detection modes

Directory listing · default

No setup. Best for small or medium folders, like a daily vendor file.

File notification · legacy

Needs cloud permissions per stream. useNotifications = true.

Managed file events · recommended

Admin enables once per external location. useManagedFileEvents = true.

CDC with COPY INTO

Insert

New row lands. Fine.

Update

A second row next to the old one.

Delete flag

Just another row.

COPY INTO only appends. Land raw history in Bronze, then MERGE into Silver on the key with the op flag and a timestamp, or use AUTO CDC.

Use COPY INTO

Daily vendor rewards file, a few hundred rows, a SQL-only team, a one-off backfill.

Use Auto Loader

Card transactions at thousands of files an hour, FICO attributes that keep changing, near real-time.

07

Managed database connectors

You choose the source, tables and target. Databricks takes the first snapshot, then keeps applying inserts, updates and deletes from the change log.

Inserts, updates and deletes travel together. SaaS connectors skip the gateway: connection (often OAuth), then the ingestion pipeline.

SourcePrerequisite
SQL ServerCDC or change tracking enabled
OracleLogMiner with supplemental logging
MySQLBinary log
PostgreSQLLogical replication
Teradata (query-based)A reliable cursor column, like last_updated. Misses hard deletes

If the gateway stops longer than the database keeps its log, the connector needs a full re-snapshot.

REST APIs and Lakeflow Jobs

import requests, json
token = dbutils.secrets.get("rewards-scope", "api-token")
page, rows = 1, []
while True:
    r = requests.get("https://api.vendor.com/offers", params={"page": page},
                     headers={"Authorization": f"Bearer {token}"}, timeout=30)
    r.raise_for_status()
    items = r.json()["items"]
    if not items: break
    rows += items; page += 1
# preferred: land raw JSON in a volume, Auto Loader picks it up
dbutils.fs.put("/Volumes/rewards/bronze/landing/offers/offers.json", json.dumps(rows), True)

Without the paging loop you get only page one. Without raise_for_status, error pages load as data.

11

Partner connectors

Fivetran, Qlik Replicate, Informatica, Matillion and others connect through Partner Connect, which sets up a trial, a service principal, a SQL warehouse and a token. They write into Unity Catalog tables using Databricks permissions.

Pick a partner when

There's no native connector, you already license one (GoldenGate or Qlik), or the setup is unusual on-premises.

Trade-offs

An extra licence, data passing through another vendor, and monitoring outside Databricks.

Don't confuse these four

Checkpoint

Auto Loader's record of which files are already loaded.

Change Data Feed

Delta's record of row inserts, updates and deletes by version. table_changes().

High-water mark

The last cursor value a query-based connector or JDBC job pulled.

Watermark

Spark streaming setting for how late events can arrive in windowed work. Not part of Auto Loader.
